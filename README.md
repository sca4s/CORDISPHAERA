# CORDISPHAERA

**🎶 CORDISPHAERA — Harmonia Kinetica (v3.2.0)**

CORDISPHAERA — Harmonia Kinetica is an interactive, pastel-themed kinetic music sandbox and visual instrument built for the browser. Combining a frosted-glass aesthetic with floating geometric sculptures, it lets players compose ambient melodies and rhythms by placing shapes, strumming vibrating strings, releasing bouncing orbs, and watching their creations translate into live scrolling sheet music in real time.

---

**✨ Key Features**
1. Three Switchable String Instruments: Switch seamlessly on the fly between a 6-String Acoustic Guitar (warm wood timbre), a 6-String Electric Guitar (detuned shimmer chorus with soft overdrive and ambient delay), and a 4-String Bass Guitar (deep sub-oscillator punch).
Harmonic Pentatonic Fret Zones: Strings are divided horizontally into five harmonic zones (Open, +2, +4, +7, and Octave), ensuring every placed shape or strum stays effortlessly in tune.
2. Built-In Percussion Tracks: Layer rhythms below the strings using dedicated Hi-Hat, Snare, and Kick drum lanes.
Harmonic Pentatonic Fret Zones: Strings are divided horizontally into five harmonic zones (Open, +2, +4, +7, and Octave), ensuring every placed shape or strum stays effortlessly in tune.
3. Kinetic Travelers & Generative Orbs: Luminous traveler pearls sweep across each lane at your chosen tempo to trigger placed geometric shapes. Spawn free-bouncing pastel orbs (+ Orb) that ricochet around the canvas and trigger nearby notes for generative polyrhythms.
Live Scrolling Sheet Music Dock: Every plucked string and drum hit is transcribed in real time onto a bottom frosted-glass staff. The score automatically switches between Treble Clef (𝄞) and Bass Clef (𝄢), rendering ledger lines, note stems, cross-noteheads for hi-hats, and pitch labels.
4. Zero-Dependency Web Audio Synthesizer: All string plucks, wood transients, guitar overdrive curves, delay tails, and drum hits are synthesized procedurally in real time using the native Web Audio API and a master dynamics compressor—no external audio files required.
5. Serene Pastel Visuals: Features an frosted-glass HUD, a multi-stop pastel gradient sky, floating 3D-shaded ambient sculptures, physical string vibration waves, and expanding bloom ripples.

**🎮 How to Play & Controls**
1. Place / Remove Notes: Tap or click anywhere along a guitar string or drum lane to drop a pastel geometric trigger shape (circle, triangle, diamond, hexagon, or squircle). Tap an existing shape to remove it.
2. Live Strumming: Click and drag (or swipe) vertically across the guitar strings to strum live chords.
3. Switch Instruments: Use the segmented picker on the launch screen or top HUD to toggle between Acoustic, Electric, and Bass.
4. Flow & Tempo: Toggle Flow: On / Paused to start or pause the kinetic travelers and orbs, and adjust the Tempo slider (1.0 to 5.6) to control playback speed.
5. Add Orbs & Reset: Click + Orb to release a free-bouncing pastel orb into the playfield, or press Clear to reset all shapes, orbs, and sheet music.

**🛠️ Technical Highlights & Deployment**
1. Single-File Portable Build: Packaged entirely within a single CORDISPHAERA.html file using HTML5 Canvas, vanilla JavaScript, and Tailwind CSS via CDN.
2. Responsive & Touch-Ready: Supports high-DPI (devicePixelRatio) canvas scaling and unified pointer events (pointerdown, pointermove, pointerup) for smooth desktop mouse and mobile touch play.
3. Quick Start: Download CORDISPHAERA.html from the release assets below and open it directly in any modern web browser.
